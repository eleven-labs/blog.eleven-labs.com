# Tokens

Lus dans `src/design-system/styles/tokens.css` (bloc `@theme` de Tailwind v4) : cette page suit le fichier sans copie. Les valeurs sombres
viennent du bloc `.dark` de `src/design-system/styles/theme.css`. Les variables de shadcn/ui (`--background`,
`--primary-foreground`, `--ring`…) pointent sur ces tokens.

Les échelles gardent les noms de Tailwind (`p-4`, `text-sm`), mais seuls les pas listés ici existent : chaque famille
est remise à zéro (`--spacing-*: initial`) puis redéclarée. Une autre classe (`p-5`, `text-[13px]`) n'est pas générée
et le lint la signale. Une valeur qui manque s'ajoute au fichier de tokens, avec son usage.

## Tailles de texte

Chaque taille porte son interligne. Une taille ne change pas selon l'écran : la variation s'écrit dans le JSX (`md:`)
ou dans la classe d'un composant.

## Espaces et dimensions

Marges, gouttières, paddings et petites dimensions (`p-4`, `gap-2`, `size-4`), puis les dimensions nommées d'après
leur usage (`h-control`). Une largeur d'écran ou de calque est une entrée nommée du thème (`max-w-measure`).
